Rank predictor data

Set the marks-vs-rank table used by the NEET rank predictor on the home page. Add a row for each marks value you have a rank for; scores in between are calculated automatically.

How to publish

  1. Edit the table below and check the test box gives sensible ranks.
  2. Click Preview on this device to see it in the real predictor on this browser only.
  3. Click Download JSON and replace public/data/rank-predictor.json in the project with the downloaded file.
  4. Rebuild and deploy the site. Every visitor now gets the new ranks.
